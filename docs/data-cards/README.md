# Data cards

[← README](../../README.md) · [Build guide](../../BUILD_GUIDE.md) · [Roadmap](../05-roadmap.md) · [Glossary](../00-glossary.md)

**What a data card is.** One page per dataset the project uses, always with
the same headings: where it comes from, what licence it carries, how big it
is, what is in it, what this project uses it for, and — the part most
projects skip — **what it cannot show**. Think of it as the label on a food
packet: ingredients, allergens, origin, and a plain statement of what the
product is not.

**Why every dataset gets one.** Three reasons. A reader should never have to
guess what data a result rests on. A non-commercial licence buried in a
download page becomes a problem the day someone reuses the work; on a card it
is impossible to miss. And "what it cannot show" is where the honesty lives —
a low-resolution multi-scanner set is a real test–retest for *tissue*
features and nothing at all for *nuclear* features, and the card says so.

**The rule.** No dataset is downloaded, cited, or used in a figure without a
card here. A card is written *before* the download script, not after.

Synthetic phantoms (both tracks) are generated by code in the repository,
labelled `synthetic: true` in every file they produce, and need no card: their
"source" is `src/stableseg/phantom.py` and `src/stableseg/pathology/phantom.py`,
and their truth is arithmetic.

**Licences, in plain words.** *CC BY* — use it for anything, credit the
authors. *CC BY-SA* — the same, and share derived data under the same terms.
*CC BY-NC-SA* — credit, share alike, **no commercial use**. *Non-commercial
research* — read the exact wording on the release page; it is recorded on the
card. When a licence is non-commercial, everything derived from that dataset
inherits the restriction, and the card says which outputs those are.
